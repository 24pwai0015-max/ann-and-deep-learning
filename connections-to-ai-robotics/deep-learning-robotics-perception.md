# Deep Learning in Autonomous Robotics & Perception

Architectural mapping between deep learning architectures and robotics (ROS 2):
- **Convolutional Perception Networks:** Feature extraction from RGB-D and stereo vision streams for obstacle detection.
- **Point Cloud Deep Learning (PointNet / VoxelNet):** 3D object detection from LiDAR sensors in real time.
- **Inference Latency & Edge Quantization:** TensorRT / ONNX runtime optimizations for embedded robotic compute (Jetson).
